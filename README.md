# Интерактивное резюме

Моё резюме в виде одностраничного сайта. Использован HTML, CSS и JavaScript.

## 🔗 Ссылка на сайт

https://hhmng.github.io/resume/

## О проекте

Страница состоит из нескольких блоков: шапка с кнопкой переключения темы, «Обо мне» с фото и контактами, «Образование», «Опыт» с местами работы, «Курсы» и «Навыки» с поиском и фильтрацией.

Навыки разбиты на четыре категории: личные качества, профессиональные навыки, инструменты и языки. Можно выбрать категорию и/или ввести текст в поиск — список обновится сразу, 
без перезагрузки страницы. Поиск нечувствителен к регистру. Если ничего не подходит под фильтр и запрос одновременно — показывается сообщение «Ничего не найдено».

Тему можно переключить кнопкой в шапке. Выбранный вариант сохраняется.

## Что реализовано

- Фильтрация навыков по категориям
- Поиск по навыкам в реальном времени
- Поиск и фильтр работают вместе
- Сообщение при пустом результате
- Светлая и тёмная тема
- Сохранение темы через `localStorage`

## Что не реализовано

- Адаптивность

## Стек

- HTML5
- CSS3 — Flexbox, Grid, CSS-переменные для тем
- Vanilla JavaScript — без библиотек и фреймворков
